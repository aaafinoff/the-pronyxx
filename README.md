# The Pronyxx — сайт студии

Сайт студии The Pronyxx: главная, каталог проектов, страницы направлений, новости, roadmap, «о студии» и контакты.
Сделан на чистом HTML, CSS и JavaScript — без сборки и без библиотек.

**Текущая версия: v0.4** (все страницы). Дальше — v1.0: живая статистика, админка, API, свой домен.

## Как запустить у себя

Сайт читает данные из JSON-файлов, а браузер не разрешает это делать, если открыть `index.html` двойным кликом.
Поэтому нужен маленький локальный сервер. Открой терминал в папке проекта и выполни:

```bash
py -m http.server 8000
```

Потом открой в браузере <http://localhost:8000>. Остановить сервер — `Ctrl + C` в терминале.

> Другой способ: в VS Code поставить расширение **Live Server** и нажать «Go Live».

## Как устроен проект

```
index.html, projects.html, ...   страницы (каркас: заголовки и пустые блоки)
data/                            ВСЁ содержимое сайта
  projects.json                  проекты
  news.json                      новости и девлоги
  roadmap.json                   дорожная карта
  directions.json                три направления
  studio.json                    слоган, соцсети, почта, цифры, история, основатель
css/
  base.css                       цвета, шрифты, сетка, анимация появления
  components.css                 шапка, подвал, кнопки, карточки, значки
  pages.css                      стили отдельных страниц
js/
  core/dom.js                    безопасное создание элементов, проверка ссылок
  core/data.js                   загрузка JSON (потом здесь подключим API)
  core/layout.js                 шапка, подвал, фон, анимации
  core/components.js             карточки проекта, новости, направления
  pages/                         по одному файлу на каждую страницу
images/                          картинки бренда (подробно — в images/README.md)
  originals/                     исходники, только их меняем руками
  brand/, icons/, directions/,   готовые версии для сайта —
  backgrounds/, social/          их собирает скрипт
tools/process_images.py          скрипт обработки картинок
```

Три страницы работают как шаблоны и берут `id` из адреса:

- `project.html?id=prism-realm` — страница проекта
- `direction.html?id=prism` — страница направления (`prism`, `security`, `apps`)
- `post.html?id=site-launch` — страница новости

## Как менять содержимое

HTML трогать не нужно — всё меняется в папке `data/`.

- **Новый проект:** добавь объект в `data/projects.json`. `id` — маленькие латинские буквы, цифры и дефис.
  `status`: `live` (работает), `dev` (в разработке), `planned` (в планах). `flagship: true` — показать на главной.
- **Новая новость:** добавь объект в `data/news.json`. `type`: `news` или `devlog`. `body` — список абзацев.
- **Картинки проектов:** положи файл в `images/projects/` и впиши путь, например `"image": "images/projects/prism-realm.webp"`.
  Пока путь пустой, вместо картинки показывается заглушка «скоро».
- **Логотипы и значки:** замени файл в `images/originals/` и запусти `py tools/process_images.py` — подробности в `images/README.md`.
- **Соцсети и почта:** `data/studio.json`. Ссылки должны начинаться с `https://`.
  Пока ссылка пустая, на сайте написано «скоро». Форма контактов заработает, когда заполнишь поле `email`.

⚠️ Сейчас в `data/` лежат **временные тексты и цифры-заглушки** — замени их на настоящие.

## Дизайн

Сайт чёрно-белый. Все цвета лежат в одном месте — в блоке `:root` файла `css/base.css`.
Цветными остаются только значки направлений (это картинки, а не CSS).

## Безопасность

- Текст из JSON вставляется только как текст (`textContent`), `innerHTML` не используется нигде — это защита от XSS.
- Все ссылки проходят проверку `safeUrl` в `js/core/dom.js`: разрешены только `https:`, `mailto:` и ссылки на сам сайт.
- `id` из адреса страницы проверяется: только `a-z`, `0-9` и дефис.
- В каждой странице есть Content-Security-Policy: браузер выполняет скрипты только с самого сайта.
- Поля формы проверяются перед отправкой.
- Секретов (паролей, ключей) в проекте нет. Когда появится бэкенд — они будут только в `.env`, и этот файл не попадает в Git.

## Как опубликовать на GitHub Pages

1. Создай на GitHub новый репозиторий и загрузи в него все файлы проекта.
2. В репозитории открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту-две сайт появится по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.

5. **Превью для ссылок.** В тегах `og:image` и `twitter:image` на каждой странице стоит полный адрес картинки
   (`https://aaafinoff.github.io/the-pronyxx/images/social/og-preview.png`). Если сайт переедет на свой домен — поменяй его.

**Сайт опубликован:** <https://aaafinoff.github.io/the-pronyxx/>

Чтобы обновить сайт после изменений, выполни в папке проекта:

```bash
git add -A
git commit -m "Что изменил"
git push
```

Все пути на сайте относительные, поэтому он работает и в подпапке GitHub Pages, и на своём домене.
