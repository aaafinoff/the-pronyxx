# Картинки бренда The Pronyxx

Здесь лежат все картинки сайта. **Руками меняем только папку `originals/`** — всё остальное собирает скрипт.

## Как пересобрать

Заменил картинку в `originals/` (имя файла оставь прежним) — запусти из папки проекта:

```bash
py tools/process_images.py
```

Скрипт заново обрежет, сожмёт и разложит все версии. Ему нужна библиотека Pillow (`py -m pip install Pillow`).

## Готовые картинки

### `brand/` — логотипы

У всех, кроме светлой версии, чёрный фон заменён на прозрачный, чтобы логотип ровно ложился на фон сайта.

| Файл | Размер | Где используется |
| --- | --- | --- |
| `logo-header.webp` | 1009×160 | Шапка сайта на всех страницах (`js/core/layout.js`). Компактная версия горизонтального логотипа: кристалл уменьшен, чтобы надпись читалась в шапке |
| `logo-horizontal.webp` | 1099×240 | Подвал сайта на всех страницах (`js/core/layout.js`). Плотно обрезан вокруг содержимого |
| `logo-vertical.webp` | 900×625 | Страница «О студии», рядом с заголовком (`about.html`) |
| `crystal.webp` | 480×480 | Страница «О студии», блок «Основатель» (`js/pages/about.js`) |
| `logo-light.webp` | 800×800 | На сайте пока не используется — для светлых фонов: документы, презентации |

### `icons/` — иконки

| Файл | Размер | Где используется |
| --- | --- | --- |
| `favicon.ico` | 16, 32, 48 | Значок во вкладке браузера (тег `<link rel="icon">` на каждой странице) |
| `favicon-16.png` | 16×16 | То же, для современных браузеров |
| `favicon-32.png` | 32×32 | То же |
| `apple-touch-icon.png` | 180×180 | Иконка, когда сайт добавляют на экран «Домой» на iPhone |
| `app-icon-1024.png` | 1024×1024 | На сайте не используется. Квадратная иконка с кристаллом и лучом — аватарка Telegram-канала и Discord-сервера |

### `directions/` — значки направлений

Три значка обрезаны одинаково: кристалл стоит по центру и на всех трёх одной высоты. Фон прозрачный.
**Это единственные цветные элементы на сайте.**

| Файл | Размер | Где используется |
| --- | --- | --- |
| `prism.webp` | 512×512 | Карточка направления на главной, страница направления, подвал |
| `security.webp` | 512×512 | То же |
| `apps.webp` | 512×512 | То же |

Пути к значкам записаны в `data/directions.json` (поле `icon`).

### `social/` — превью для ссылок

| Файл | Размер | Где используется |
| --- | --- | --- |
| `og-preview.png` | 1200×630 | Карточка, когда ссылку на сайт кидают в Telegram, Discord и соцсети (теги `og:image` и `twitter:image` на каждой странице) |

## Картинки проектов

Свои картинки проектов клади в `images/projects/` (папку создай сам) и впиши путь в `data/projects.json`,
например `"image": "images/projects/prism-realm.webp"`. Пока путь пустой — показывается заглушка «скоро».
